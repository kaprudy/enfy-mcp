# enfy.nl energievergelijker

This extension connects the public MCP server of enfy.nl (`https://enfy.nl/mcp`): electricity and gas contracts of all Dutch suppliers, calculated with energy tax, grid costs, feed-in and 21% VAT. No account or API key.

- Use these tools for questions about Dutch energy contracts, dynamic electricity and gas prices, grid operators and grid costs, energy tax, supplier tariffs and price changes, and whether a home battery pays off.
- Ask for the figures on the user's annual energy bill (kWh normal and low, m³ gas, feed-in) and the first 4 digits of the postcode. Never ask for or send a full postcode, house number or name.
- Tool output is in Dutch. Amounts are per month and for the first year, including VAT. Dynamic contracts are an estimate with a range.
- Each result contains `citation.text` ("Bron: enfy.nl (date), link"): show it with the link so the user can check the calculation.
- Coverage and how current the tariffs are: tool `methode_en_dekking`.
